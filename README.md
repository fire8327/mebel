# Универсальный адаптивный лендинг фабрики мебели (Чебоксары)

Современный высококонверсионный лендинг на чистых веб-технологиях (Vanilla HTML5, CSS3, ES6+ JavaScript) без тяжелых сторонних фреймворков.

Проект спроектирован как универсальный шаблон с **строго индивидуальной параметрической презентацией**: для каждого клиента сайт открывается по уникальной ссылке и выглядит на 100% как эксклюзивный авторский проект без каких-либо признаков шаблонизации.

---

## 🔒 Параметрический доступ

Прямой вход без параметров (или с некорректным параметром) закрыт: пользователю отображается минималистичная страница **404** («Доступ возможен только по персональной ссылке от менеджера»).

## 🎨 Динамическая адаптивная палитра под цвета брендов

Сайт больше не привязан к единому жёлтому цвету. В зависимости от логотипа компании, цветов групп ВКонтакте и стиля отзывов автоматически перестраивается вся CSS-палитра (кнопки, градиенты заголовков, бейджи, подсветки карточек, активные элементы калькулятора, слайдеры и тени):
* **«Виктория Мебель»** — глубокий рубиново-алый акцент в тон красному фирменному яблоку/ягоде в логотипе (`#E11D48`).
* **«Аванта Мебель»** — современный лазурно-бирюзовый/циан акцент в тон геометрическому архитектурному знаку (`#0EA5E9`).
* **«Вита Мебель»** — свежий эко-изумрудный акцент в тон зеленой бабочке/листку «Вита» (`#10B981`).
* **«АСМЕБЕЛЬ 21»** — теплый энергичный оранжево-терракотовый акцент в тон официальному оранжевому креслу-логотипу (`#F54F29`).

## 🛠 Технологии и архитектура

* **Vanilla HTML5 & CSS3**: современные CSS Grid, Bento Grid, Flexbox, CSS переменные, плавные микроанимации.
* **ES6+ JavaScript**: динамический рендеринг DOM, интерактивный калькулятор сметы, модальные окна, ленивая подгрузка.
* **Полная изоляция ассетов**: фото-галереи, логотипы, сертификаты и отзывы строго изолированы в папках `assets/<brand>/` — нулевое пересечение между компаниями.
* **Адаптивность**: оптимизировано под мобильные экраны, планшеты и десктопы (включая фиксированный мобильный бар быстрых действий звонка и WhatsApp).


## 🚀 Запуск проекта

Так как проект выполнен на чистых технологиях, для запуска достаточно любого статического веб-сервера:

```bash
# Через Python:
python -m http.server 8080

# Открыть в браузере с нужным брендом:
http://localhost:8080/?brand=avanta
```
